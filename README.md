# Аналитика инвестиций

Портфель по отчётам брокеров (Сбер, ВТБ, Т-Банк, Финам), вклады, цели, скринеры и аналитика.
Всё работает в браузере: отчёты и настройки хранятся только на вашем устройстве
(или в вашем зашифрованном хранилище Cloudflare(cоздать аккаунт нужно), если включена синхронизация).

## Как установить на телефон

- **iPhone / iPad:** откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте адрес в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
