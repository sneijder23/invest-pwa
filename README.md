# Аналитика инвестиций

Портфель по отчётам брокеров (Сбер, ВТБ, Т-Банк, Финам), вклады, цели, скринеры и аналитика.
Всё работает в браузере: отчёты и настройки хранятся только на вашем устройстве
(или в вашем зашифрованном хранилище Cloudflare, если включена синхронизация).

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на github.com (например, `portfel`).
2. Загрузите в него **все файлы из этой папки**: Add file → Upload files → перетащите их → Commit changes.
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты приложение будет доступно по адресу `https://<ваш-логин>.github.io/portfel/`.

## Как установить на телефон

- **iPhone / iPad:** откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте адрес в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

## Как обновлять

Загрузите новый `index.html` в репозиторий поверх старого. Приложение подхватит его при следующем запуске с интернетом.

## Важно

- Бесплатный GitHub Pages работает только для **публичных** репозиториев — код приложения будет виден всем.
  Ваши данные в код не попадают: отчёты, ключи API и пароли остаются в браузере.
- У сайта на github.io своё хранилище: данные из файла, открытого раньше, сюда сами не переедут.
  Включите синхронизацию через Cloudflare (иконка облака) на старом и новом месте — или загрузите отчёты заново.
